# Dataset

The primary ridership dataset used in this project is larger than GitHub's standard web upload limit, so the complete `Ridership.csv` file is not stored directly in this repository.

The analysis was performed using the complete dataset locally.

Other supporting datasets used in the project are included where their file sizes permit.

## Main Dataset

**Ridership.csv**

The dataset contains daily Lahore Metro Bus ridership records used for:

- Ridership trend analysis
- Station performance analysis
- Seasonal analysis
- Holiday impact analysis
- Weather analysis
- Growth analysis
- KPI calculations

The Power BI dashboard and SQL analysis were developed using the complete dataset.
